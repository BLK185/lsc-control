# Connexion LSC sur une installation neuve — 0.3.0

La connexion ne demande plus de fichier privé fourni par le développeur. Dans **Connexion LSC → Préparer la connexion LSC**, laisser télécharger environ 64 Mo de composants officiels Action et 7-Zip, puis scanner le QR dans LSC Smart Connect et confirmer sur téléphone. Les versions et empreintes sont vérifiées ; les installateurs sont extraits sans être exécutés. Le téléphone peut afficher « LSC Battletron » lors de l’autorisation.

Les composants sont préparés uniquement dans le profil du poste. Aucun compte partagé, aucune session, clé d’ampoule ou identité personnelle du développeur n’est livré. Les versions antérieures conservant un module privé fonctionnent toujours.

## Fichiers Windows x64

- `LSC-Control-0.3.0-windows-x64-setup.exe` : installation par utilisateur.
- `LSC-Control-0.3.0-windows-x64-portable.zip` : extraire tout le dossier avant lancement.
- `SHA256SUMS.txt` : empreintes des fichiers.

## Vérifications et limites

130 tests automatiques passent. Le téléchargement officiel et la préparation ont été exécutés avec un profil vide ; un vrai QR serveur a été obtenu sans session enregistrée ni module privé. Une lecture authentifiée séparée a retrouvé le compte avec le nouveau runtime, sans commander les éclairages ni modifier de planning.

La préparation repose sur Battletron 2.0.17 et 7-Zip 26.04, dont les téléchargements sont épinglés. Elle dépend de la disponibilité des sources et du service LSC. Elle ne fournit pas de support officiel de LSC Control par Action/Tuya. Le programme reste expérimental et non signé. Appairage initial toujours dans l’application mobile ; synchronisation Windows et planning partagé conservés.
