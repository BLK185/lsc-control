# Éclairages du compte — 0.2.0

LSC Control affiche les éclairages reconnus de votre compte, avec synchronisation automatique des ajouts, retraits et noms environ toutes les 30 secondes. Plusieurs appareils du même modèle sont acceptés. La grille et le menu près de l’horloge s’adaptent à la liste et aux fonctions déclarées.

Les commandes « Tout allumer / Tout éteindre » ciblent désormais correctement chaque appareil, même pendant une lecture. Les réglages avancés sont retirés ; une connexion locale rapide reste disponible sans saisie technique. Les boîtiers HDMI et les appareils non lumineux sont exclus.

## Fichiers Windows x64

- `LSC-Control-0.2.0-windows-x64-setup.exe` : installation par utilisateur, sans droits administrateur.
- `LSC-Control-0.2.0-windows-x64-portable.zip` : extraire tout le dossier avant de lancer le programme.
- `SHA256SUMS.txt` : empreintes des fichiers.

Le programme reste expérimental et non signé. Une installation existante conserve son profil et son coffre Windows.

## Connexion et limites

Le module privé compatible pour la connexion QR doit toujours être importé localement ; aucune identité fabricant, session ou clé d’ampoule n’est redistribuée. La démonstration fonctionne sans compte. L’appairage initial se fait dans LSC mobile, puis l’éclairage apparaît sur Windows. L’appairage Windows natif reste à développer et valider.

La détection repose sur les catégories Lighting et les schémas disponibles, sans garantir tous les produits du catalogue. Les A65 CCT et A60 RGB-CCT sont les appareils utilisés pour les essais réels. Les variations de scènes et les autres modèles restent à confirmer physiquement.

## Vérification

113 tests automatiques sans compte réel couvrent notamment les catalogues de taille variable, les changements de nom, l’exclusion HDMI, les commandes conditionnelles et la file Qt avec trois cibles. Une lecture réelle du compte a retrouvé les deux éclairages et leur état sans envoyer de commande. Les sources et paquets sont contrôlés pour exclure les données privées avant publication.
